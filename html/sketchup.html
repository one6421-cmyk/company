SketchUp
건축·인테리어·제품 디자인을 위한 3D 모델링 솔루션

SketchUp은 Trimble이 개발한 3D 모델링 소프트웨어로,
직관적인 인터페이스와 빠른 학습 곡선으로 건축·인테리어·조경 분야에서 폭넓게 사용됩니다.
2D 도면 작업을 위한 LayOut, DWG/IFC 등 주요 CAD 포맷과의 호환을 지원합니다.

용도별 에디션

SketchUp Go
웹·모바일 기반의 가벼운 3D 모델링. 외부에서 빠르게 아이디어를 스케치하고 협업하는 데 적합합니다.
SketchUp Pro
데스크톱 전체 기능과 LayOut을 포함한 표준 에디션. 전문 설계·도면 작업에 가장 널리 사용됩니다.
SketchUp Studio
Revit 가져오기, 포인트 클라우드 모델링, V-Ray 렌더링을 추가로 제공하는 고급 에디션입니다.

핵심 기능

직관적인 모델링

드래그 기반의 단순한 조작으로
복잡한 3D 형태를 빠르게 구성합니다.

LayOut

3D 모델을 치수, 주석이 포함된
2D 도면 문서로 변환합니다.

3D Warehouse

가구, 마감재, 부품 등 제조사 기반의
방대한 3D 에셋 라이브러리입니다.

Extension Warehouse

렌더링, 에너지 분석, 파라메트릭 디자인 등
전문 워크플로우를 위한 확장 도구입니다.

Revit 연동 (Studio)

Revit Importer로 BIM 워크플로우와
연계한 협업이 가능합니다.

V-Ray 렌더링 (Studio)

고품질 포토리얼 렌더링을
SketchUp 안에서 바로 사용합니다.
