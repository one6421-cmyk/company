주요 기능

수분 내 즉시 복구

Instant Recovery·Replica 기능으로 장애 발생 시 가상 서버로 수분 내 서비스 재개. 원격지 DR 환경에서도 Instant Recovery 적용 가능

용량 기반 무제한 라이선스

백업 대상 실제 데이터 크기 기준 라이선스. 서버 수·종류 무제한 백업. 별도 옵션 없이 원격 소산·중복제거 등 모든 기능 기본 포함

머신러닝 랜섬웨어 탐지

ML 기반 랜섬웨어 탐지 엔진으로 실시간 백업 파일 스캔. 랜섬웨어 의심 즉시 알림. 감염 이전 깨끗한 백업본으로 서비스 즉시 복구

Audit Mode 복구 테스트

실제 서비스 중단 없이 Audit Mode로 복구 테스트·모의 훈련 진행. 백업 데이터 유효성을 정기적으로 검증해 복구 실패 방지

AES-256 + FIPS 140-2 준수

저장·전송 전 구간 AES-256 암호화. 미국 연방 정보처리표준(FIPS) 준수로 정부·금융·의료 등 규정 준수 환경 완벽 대응

D2D2x 다계층 스토리지

Disk→Disk→Cloud·Tape·원격지 어플라이언스로 이어지는 유연한 3-2-1 백업 구성. 온사이트·오프사이트 동시 보호

Agentless 백업

에이전트 설치 없이 VMware·Hyper-V 가상 환경 백업. 운영 중인 VM에 영향 없이 일관된 백업 수행

통합 중앙 관리

단일 콘솔로 물리·가상·클라우드 전체 백업 현황 모니터링. Legacy 개별 관리에서 통합 관리 환경으로 IT 운영 효율 극대화
