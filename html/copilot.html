주요 기능

Copilot이 하는 일

단순 질답을 넘어, 실제 업무 흐름 속에서 AI가 함께 작업합니다.

문서 초안 작성

키워드나 개요만 입력하면 Word 문서, 이메일, 보고서 초안을 수초 내에 생성합니다.

데이터 분석

Excel에서 자연어로 질문하면 복잡한 수식 없이 차트 생성, 트렌드 분석, 인사이트 도출이 가능합니다.

회의 요약 & 노트

Teams 회의를 자동으로 녹취·요약하고 액션 아이템을 추출합니다. 회의에 집중하세요.

이메일 요약 & 작성

Outlook에서 긴 메일 스레드를 한 줄로 요약하거나, 어조에 맞는 답장을 자동 초안화합니다.

프레젠테이션 생성

PowerPoint에서 텍스트만 입력하면 디자인이 완성된 슬라이드를 자동으로 만들어 줍니다.

AI 기반 검색

키워드가 아닌 자연어로 사내 파일, 이메일, 채팅을 검색하여 원하는 정보를 즉시 찾아줍니다.

프롬프트·응답은 AI 모델 학습에 절대 사용되지 않습니다.

권한 기반 접근

기존 Microsoft 365 권한·민감도 레이블을 그대로 반영합니다.

규정 준수

ISO 27001, SOC 2, GDPR 등 글로벌 보안 기준을 충족합니다.

IT 중앙 관리

관리 센터에서 Copilot 기능·에이전트를 조직 단위로 제어합니다.

FAQ

네, Microsoft 365 Copilot은 Microsoft 365 Business 또는 Enterprise 플랜에 추가로 구독하는 방식입니다. 기존 Microsoft 365 구독이 없다면, 두 서비스를 함께 시작하는 통합 패키지를 추천드립니다.
Copilot은 Microsoft 365의 기존 권한 설정을 그대로 따릅니다. 특정 파일에 접근 권한이 없는 직원은 Copilot을 통해서도 해당 파일에 접근할 수 없습니다. 또한 모든 데이터는 암호화되어 처리되며, AI 모델 학습에 사용되지 않습니다.
네, Microsoft 365 Copilot은 한국어를 완벽히 지원합니다. 한국어로 질문하고 한국어 문서를 작성하는 것이 가능하며, Teams 회의 요약도 한국어로 제공됩니다.
무료 Copilot Chat은 웹 브라우저에서 사용하는 일반 AI 채팅입니다. 유료 Microsoft 365 Copilot은 Word, Excel, PowerPoint, Outlook, Teams 등 업무 앱에 직접 통합되어 사내 데이터(이메일, 파일, 캘린더 등)를 기반으로 맥락을 이해하고 작업합니다.
기존 Microsoft 365 앱 안에 자연스럽게 통합되어 있어 별도의 복잡한 교육 없이 바로 사용할 수 있습니다. 저희 파트너사에서 초기 설정 지원 및 사용자 교육 세션을 무료로 제공해 드립니다.
