대화형 디스어셈블러

바이너리 로드 즉시 전체 자동 분석. 코드·데이터 구조를 사용자가 직접 정의·수정하며 분석을 실시간으로 개선. 그래프 뷰로 코드 구조 한눈에 파악

Hex-Rays 디컴파일러

C/C++ 컴파일러 기반 바이너리를 C 수준 의사 코드로 복원. 분석이 어려운 어셈블리를 사람이 읽기 쉬운 코드로 변환해 분석 시간 단축

70개 이상 프로세서 지원

x86·x64·ARM·ARM64·MIPS·PowerPC·RISC-V 등 70개 이상 아키텍처 분석. PE·ELF·Mach-O·DEX 등 다양한 바이너리 포맷 지원

멀티 플랫폼 디버거

로컬·원격 디버거 통합. WinDbg·GDBServer 등 다양한 디버거 모듈 지원. 정적 분석에 동적 분석을 더해 실행 중 동작 파악

IDAPython·IDC 스크립팅

Python(IDAPython)·IDC 내장 스크립팅으로 분석 자동화. 플러그인 SDK 제공으로 커스텀 분석 도구 개발 가능. 방대한 플러그인 생태계

FLIRT 라이브러리 인식

F.L.I.R.T. 기술로 표준 라이브러리 함수를 자동 인식·레이블링. 알려진 코드를 빠르게 제외하고 분석 대상에 집중 가능

IDA Teams 협업 분석

팀원이 동일 IDB 파일을 병합·공유하며 협업 분석. IDA Pro와 엔진 공유로 Pro에서 수행한 작업을 Teams에서 바로 활용
