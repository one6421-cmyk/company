OrCAD X PCB 솔루션
회로도 캡처 · PSpice 시뮬레이션 · PCB 설계 통합 플랫폼

전자 설계 자동화(EDA) 업계의 세계 표준 아키텍처.
새로워진 차세대 OrCAD X 플랫폼을 통해 회로도 설계부터 PCB 레이아웃·배선·DRC/ERC 검사·Gerber 출력까지 PCB 설계 전 과정을 단일 환경에서 지원합니다.
수백만 개의 클라우드 CAD 심볼 및 3D 모델 라이브러리가 내장되어 있으며, PSpice 시뮬레이터 연동으로 설계 오류를 실시간으로 검증합니다.

제품 구성

CaptureCIS
OrCAD Capture / CIS
글로벌 표준 전자 회로 제작 및 문서화 설계 솔루션입니다. 부품 정보 시스템인 CIS를 통해 효율적으로 데이터를 관리하며 개념 설계부터 최종 생산 단계까지 끊김 없는 통합 환경을 제공합니다.
PSpice시뮬
OrCAD PSpice & 고급 분석
독보적인 아날로그 및 혼합신호 회로 시뮬레이터입니다. 회로도 설계 환경 내에서 가상 테스트를 직접 수행할 수 있으며 다양한 고급 분석 기능으로 부품 수율과 설계의 신뢰성을 사전에 검증합니다.
PCBDesigner
OrCAD X PCB Designer

AllegroPCB
Cadence Allegro PCB
OrCAD 상위 단계의 엔터프라이즈급 실리콘 패키지 보드 협업 설계 툴입니다. 고성능 Sigrity 분석 및 IC 패키지 설계를 포함하여 대규모 복합 보드 설계 환경에 가장 최적화되어 있습니다.

주요 기능

회로도 캡처 · 계층 설계

다중 페이지 및 계층화 구조의 직관적인 회로도 설계 환경을 제공합니다. OrCAD CIS 부품 정보 시스템을 통해 실시간 부품 데이터 연결 및 제조사 데이터베이스 연동을 지원합니다.

PSpice 시뮬레이션 (옵션)

아날로그 및 디지털 혼합신호 회로를 설계 환경 내에서 직접 가상 테스트합니다. DC, AC, Transient 분석부터 Monte Carlo 분석을 통해 부품 수율과 신뢰성을 사전 검증합니다.

PCB 레이아웃 · 동적 배선

사용자 친화적인 인터페이스 기반의 실시간 동적 배선 기술을 지원합니다. 물리적 요구사항에 맞춘 다층 PCB 라우팅 및 실시간 3D 미리보기 렌더링으로 실장 간섭을 미리 검토합니다.

DRC · ERC 설계 규칙 검사

전기적 규칙(ERC)과 기하학적 제조 규칙(DRC) 검사를 실시간 자동 수행합니다. 물리적 설계 오류를 실물 보드 제작 전에 완벽하게 포착하여 불필요한 시제품 재작업 비용을 획기적으로 낮춥니다.

Gerber · IPC-2581 표준 출력

PCB 양산 제조에 필요한 필수 Gerber 포맷 및 드릴 파일, ODB++를 지원합니다. 차세대 통합 데이터 규격인 IPC-2581 포맷 출력을 통해 제조사와의 원활한 데이터 교환이 가능합니다.

클라우드 부품 라이브러리

검증된 수백만 개 이상의 클라우드 기반 CAD 심볼, 풋프린트, 3D 모델을 즉시 다운로드하여 배치할 수 있습니다. 글로벌 주요 부품 유통사 인벤토리와 실시간 연동이 가능합니다.

이기종 툴 데이터 마이그레이션

Altium Designer, PADS 등 타사 EDA 소프트웨어로 작성된 과거 회로도 데이터 및 라이브러리를 손실 없이 안전하게 변환하고 마이그레이션할 수 있는 전용 트랜스레이터를 내장하고 있습니다.

Allegro 연동형 상위 신호 검증

고속 신호선의 임피던스 매칭, 크로스토크(누화), 전원 노이즈를 제어하기 위한 고성능 분석 환경을 제공합니다. 상위 엔터프라이즈(Allegro) 라인업과의 100% 데이터 호환성으로 설계를 안전하게 확장합니다.
