사이버다임이 개발한 패키지형 문서중앙화 솔루션. 중앙 서버 기반 문서 저장·통합 관리·접근 권한 제어·외부 반출 통제·이력 추적 기능을 제공합니다. 구축형·어플라이언스·클라우드(SaaS) 3가지 도입 방식으로 스타트업부터 대기업까지 기업 규모에 맞게 선택 가능합니다.

문서 중앙 저장·통합 관리

접근 권한 제어

폴더·문서 단위 세밀한 권한 설정. 부서·직급별 접근 통제로 기밀 문서 무단 열람 방지. 문서 등록 시점부터 암호화 기본 적용

외부 반출 통제

모바일·웹에서 외부 반출 요청·승인 워크플로. URL 문서 링크로 협력사와 안전하게 공유. 반출 이력 전체 추적

버전·이력 관리

특정 버전 지정 배포, 이전 버전 복원 지원. 문서 수정 이력 추적으로 안심하고 파일 작성. 실수로 덮어쓴 파일도 복구 가능

AI 챗봇 어시스턴트

중앙 서버 문서 기반 정보 추출·검색·요약 AI 챗봇. 필요한 문서를 자연어로 검색하고 핵심 내용을 즉시 파악

3D CAD 대용량 파일 지원

2024년 신제품에서 3D CAD 등 대용량 파일 작업 사용성 개선. 제조·설계 기업의 무거운 파일도 중앙 문서함에서 쾌적하게 작업

모바일 앱 (iOS·Android)

스마트폰·태블릿에서 실시간 문서 열람·등록·관리. 즐겨찾기·상세 검색·알림 설정·다크모드 지원. 재택·출장 업무 환경 구현

랜섬웨어·악성코드 공격 감지 시 원격 차단. 내부 직원·퇴직자 유출 통제. 중앙 서버의 안전 구역을 별도로 격리해 감염 확산 방지

엠클라우독 · 20년+ 노하우 · 11만 유저

ClouDoc (클라우독)EDMS·DLP·DRM 통합 원 에이전트 문서중앙화

엠클라우독(mcloudoc)이 20년 이상 개발해온 문서중앙화 솔루션. EDMS·DLP·DRM 기능을 하나의 에이전트로 통합해 개별 솔루션 도입 대비 비용과 운영 부담을 대폭 줄입니다. 자체 개발한 윈도우 탐색기 드라이브 기술로 사용자는 C드라이브에 저장하는 것처럼 자연스럽게 문서를 중앙화할 수 있습니다.

EDMS·DLP·DRM 원 에이전트 랜섬웨어 4단계 대응 AiDoc AI 지식관리 연동 윈도우 탐색기 드라이브 방식 국내외 500개+ 고객사

윈도우 탐색기 드라이브 방식

자체 개발 탐색기 드라이브 기술. 사용자는 C드라이브에 저장하듯 자연스럽게 사용. 별도 학습·교육 없이 즉시 적응 가능

랜섬웨어 4단계 대응

1단계 화이트리스트 → 2단계 I/O 패턴 차단 → 3단계 자동 버전 관리 → 4단계 백업. 감염 시 100% 문서 복구 보장

DRM·DLP 통합 보안

문서 암호화(DRM)·유출 방지(DLP)·로컬 저장 통제·클립보드 복사 금지·화면 캡처 금지·인쇄 제어·프린트 워터마크를 단일 에이전트로

AiDoc AI 지식관리 연동

AI 기반 문서 카테고리 자동 분류, 실시간 문서·전문가 추천. ClouDoc과 결합해 기업 지식 자산을 AI로 효율 관리

이미지 텍스트 추출 검색

윈도우 탐색기에서 문서 내용 검색·이미지 텍스트 추출 검색 지원. 스캔 문서·사진 속 텍스트도 전문 검색 가능

외부 DRM 반출

외부 반출 시 문서 암호화 적용. 수신자 환경에서도 DRM 보호 상태로 열람. 반출 유효기간·열람 횟수 제한 설정 가능

네트워크 락·망 분리 대응

내·외부 망 분리 통한 네트워크 통제. 네트워크 락으로 미승인 경로 접속 차단. 폐쇄망·보안망 환경에서도 안정적으로 운영

백업 어플라이언스 연계

클라우독 백업 어플라이언스로 스냅샷·증분·자동 스케줄 백업. 랜섬웨어 감염 시 중앙 문서함 저장 파일 100% 복구 보장
