핵심 기능

XtraGrid — 고성능 데이터 그리드

DirectX 하드웨어 가속 기반 초고속 렌더링. 대용량 데이터 가상화·그루핑·필터링·조건부 서식·인라인 편집 완벽 지원

XtraCharts — 강력한 차트 라이브러리

2D·3D 차트 60여 종 제공. 실시간 데이터 바인딩, 인터랙티브 드릴다운, 주석·범례 완전 커스터마이징 지원

XtraReports — 엔터프라이즈 보고서

WYSIWYG 보고서 디자이너. PDF·Excel·Word·HTML 출력. 바코드·차트·크로스탭·서브리포트 내장. 웹 보고서 뷰어 제공

BI Dashboard — 분석 대시보드

드래그 앤 드롭 대시보드 빌더. KPI·차트·그리드·피벗·맵을 조합해 분석 화면 구성. 다중 데이터 소스 연결 지원

AI 스마트 기능 통합

Azure OpenAI·ONNX·Ollama 연동. 데이터 그리드·보고서·리치 텍스트에 AI RAG·Chat Assistant·스마트 텍스트 처리 통합

Office File API

MS Office 설치 없이 Word·Excel·PDF 파일 생성·편집·변환. 서버 사이드 문서 처리와 보고서 자동화에 활용

리치 텍스트 에디터

Word 수준의 WYSIWYG 편집기. 모든 DevExpress 플랫폼에 통합 가능. AI 기반 스마트 텍스트 처리·요약·번역 기능 탑재

프로젝트 템플릿 갤러리

WinForms v24.2부터 제공되는 프로젝트 템플릿 갤러리. 주요 레이아웃·UI 의사결정을 자동화해 개발 시작 속도 향상
