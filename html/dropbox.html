스마트 동기화

로컬 디스크 공간을 차지하지 않고 파일을 온라인 전용으로 설정. 필요할 때만 다운로드해 하드 드라이브 절약

파일 버전 관리

Standard 180일, Advanced 1년간 변경 이력 보관. 실수로 수정·삭제한 파일을 IT 도움 없이 즉시 복구

보안 공유 링크

만료일·비밀번호 설정, 본 사람 기록, 워터마크까지 — 링크 하나로 접근 권한을 세밀하게 제어

대용량 파일 전송

Dropbox Transfer로 이메일 첨부 한계 없이 대용량 파일 전송. 수신 확인 및 다운로드 횟수 제한 설정 가능

전자 서명 (eSign)

Dropbox 내에서 무제한 전자 서명 요청·발송. 법적 구속력 있는 서명을 별도 앱 없이 워크플로에 통합

관리 콘솔

팀원 추가·권한 설정·장치 관리를 한 화면에서. 감사 로그로 데이터 공유 현황을 상세하게 추적

Dropbox Replay (영상 협업)

영상·오디오 파일에 시간 지정 댓글 및 승인 워크플로. 반복 회의 없이 비디오 프로젝트 피드백 간소화

원격 장치 삭제

분실·도난 기기에서 Dropbox 파일 원격 삭제. 퇴사자 장치 접근 차단까지 관리자가 즉시 처리

외부 앱 연동

Slack·Microsoft Teams·Google Workspace·Zoom 등 300개+ 앱과 연동. 기존 업무 툴에 Dropbox를 자연스럽게 통합

컴퓨터 백업

바탕화면·문서·다운로드 폴더 자동 백업. 기기 교체나 장애 시에도 데이터 손실 없이 즉시 복원

PDF 편집·서명

Dropbox 내에서 PDF 준비·편집·전자 서명을 원스톱 처리. 계약서·문서 워크플로를 단일 플랫폼에서 완결

Dropbox Vault

가장 민감한 파일을 별도 보호 공간에 저장. PIN 설정과 신뢰 연락처 공유로 중요 문서를 이중 보호
