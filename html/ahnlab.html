EPP를 구성하는 5가지 솔루션

AhnLab EPP는 V3(백신)·EPM(패치관리)·EPrM(개인정보보호)·ESA(보안점검)·EDR(행위탐지)의 5가지 솔루션으로 구성됩니다. 각 솔루션은 EPP 플랫폼 위에서 서로 연계되어 단독 사용 대비 훨씬 강력한 엔드포인트 하드닝 효과를 제공합니다.

EPrM
EPP Privacy Management
개인정보 유출 방지
엔드포인트의 이메일·웹메일·프린터·USB 등 주요 경로에서 개인정보 파일 유출을 탐지·차단. 임직원에게 직관적인 팝업 알림으로 개인정보 보호 인식을 높이고, 미처리 파일 초과 시 자동 캠페인을 실행합니다.
ESA
EPP Security Assessment
취약 시스템 점검·조치
국내 최대 수준 75개 점검 항목으로 PC 보안 상태를 감사하고 자동 조치. IT 비전문가도 쉽게 보안 조치를 수행할 수 있으며, 관리자 지정 점검 항목을 추가해 조직 맞춤 보안 강화(Hardening)가 가능합니다.
EDR
AhnLab EDR
엔드포인트 탐지 & 대응
V3·MDS를 우회한 알려지지 않은 위협을 행위 분석·타임라인·상관 분석으로 탐지·대응. 위협 잠복기(dwell time)를 최소화하며, EPP 연계 정책으로 파일 자동 수집·삭제 등 즉각적인 대응 조치를 수행합니다.

EPP 구성 제품 공통 핵심 기능

V3 — 다차원 위협 분석

시그니처·행위·ASD 클라우드 분석 결합. 랜섬웨어·제로데이 공격을 사전에 탐지하고 감염 경로를 추적

EPM — 중앙 패치 배포

패치랩 사전 검증 완료 패치만 배포. IP별 네트워크 허용·차단 현황 모니터링과 패치 진행 상태 실시간 추적

EPrM — 유출 경로 탐지

이메일·웹메일·클라우드·USB·프린터 등 개인정보 이동 경로 전반 모니터링. 의심 행위 즉시 차단·알림

ESA — 75개 보안 점검

국내 최대 규모 점검 항목. 자동·백그라운드 조치로 관리자 개입 없이 엔드포인트 하드닝 수준 유지

EDR — 행위 타임라인 분석

엔드포인트의 모든 행위를 기록·분석. 공격 흐름을 타임라인으로 시각화해 침해 사고 원인을 즉시 파악

EPP 연계 자동 대응

탐지 조건 충족 시 네트워크 격리·악성코드 치료·패치 적용·점검 수행을 연계 정책 기반으로 자동 실행
