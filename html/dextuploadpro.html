대용량 파일 업로드

최적화된 파싱 알고리즘으로 GB급 대용량 파일도 낮은 서버 리소스로 빠르게 처리. 서버 부하 최소화로 안정적 서비스 운영

멀티 파일 동시 업로드

여러 파일을 한 번에 선택·업로드. 폴더째 업로드, 드래그 앤 드롭 UI 지원. 파일별 진행 상태 실시간 표시

파일 이어받기 (Resume)

업로드 중 네트워크 끊김 발생 시 이어받기 지원. 청크 단위(기본 10MB) 분할 전송으로 안정적인 대용량 전송 보장

이미지 처리·변환

업로드된 이미지를 BMP·JPG·GIF·TIFF·PNG로 변환. 이미지 크기·포맷·해상도 정보 자동 추출. 별도 이미지 컴포넌트 불필요

파일·폼 데이터 통합 처리

파일과 일반 폼 데이터(텍스트·숫자 등)를 한 번의 요청으로 함께 처리. 복잡한 업로드 폼도 단순하게 구현

보안·접근 제어

업로드 파일 형식·크기 제한, 악성 파일 차단 정책 설정. 허용 확장자 화이트리스트 관리로 보안 취약점 원천 방지

크로스 브라우저·OS 지원

X5는 Chrome·Firefox·Safari·Edge 모든 브라우저 지원. Windows·macOS·Linux 크로스 플랫폼. iOS·Android 모바일 브라우저도 지원

전자정부 프레임워크 호환

행정기관 표준 전자정부 프레임워크 환경에서 검증 완료. 공공기관·지자체 웹 시스템 구축에 안정적으로 적용
