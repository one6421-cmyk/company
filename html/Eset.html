ESET Endpoint 제품군

Endpoint Antivirus & SecurityOS별 최적화된 엔드포인트 보호

Windows·macOS·Linux·Android 모든 플랫폼에서 NOD32 기반 다계층 보호를 제공하는 ESET 엔드포인트 제품군. 랜섬웨어 실드·네트워크 공격 방어·장치 제어 등 강력한 보안 기능을 가벼운 엔진으로 구현합니다.

Endpoint Security (Windows)
랜섬웨어 실드, 네트워크 공격 방어, 장치 제어, 방화벽, 피싱 방지 기능을 제공합니다. ARM64 기반의 Windows를 지원하며, ESET PROTECT 콘솔을 통한 중앙 관리가 가능합니다.
Endpoint Security (macOS)
Apple Silicon(ARM)을 기본으로 지원하며, macOS 10.12 이상 환경과 호환됩니다. 실시간 악성코드 및 피싱 차단 기능과 웹 제어 기능이 포함되어 있습니다.
Endpoint Antivirus (Linux)
Ubuntu, RHEL 등 주요 Linux 배포판을 지원합니다. 서버와 데스크톱 환경을 모두 커버하며, 명령줄(CLI) 방식 및 PROTECT 콘솔 관리를 지원합니다.
Mobile Security (Android)
Android 6.0 이상 버전을 지원합니다. 악성 앱 및 피싱 차단, 앱 잠금, 도난 방지, MDM 통합 관리 기능을 제공하며, iOS 환경에는 일부 프라이버시 기능을 제공합니다.
File Server Security
Windows Server 및 Linux 파일 서버를 실시간으로 보호합니다. 특히 네트워크를 통한 랜섬웨어 확산 차단에 특화되어 있으며, 가상 환경(VMware vSphere) 연동을 지원합니다.
Full Disk Encryption
Windows와 macOS 전체 디스크 암호화 기능을 제공합니다. GDPR, PCI 등 글로벌 데이터 보호 규정을 준수할 수 있으며, PROTECT 콘솔에서 원격으로 암호화 상태를 모니터링할 수 있습니다.

VB100 세계 최초 100회 인증

Virus Bulletin의 VB100 테스트를 세계 최초로 100회 통과했습니다. 또한 글로벌 독립 평가 기관인 AV-Comparatives와 AV-TEST에서도 지속적으로 최고 등급을 획득하고 있습니다.

낮은 시스템 부하

경량 설계로 시스템 리소스를 최소한으로 점유합니다. 구형 하드웨어에서도 원활하게 동작하여 업무용 PC 성능에 영향을 주지 않고 안전하게 보호합니다.

오탐(False Positive) 최소화

정밀한 탐지 알고리즘을 통해 오탐률을 최저 수준으로 유지합니다. 정상 프로그램이 오인 차단되어 업무가 중단되는 현상 없이 안정적인 운영이 가능합니다.

랜섬웨어 실드

모든 ESET 엔드포인트 제품에 기본 탑재된 랜섬웨어 전용 방어막입니다. 파일 암호화 시도를 실시간으로 차단하고 감염 전 상태로 안전하게 롤백합니다.

네트워크 공격 방어

네트워크 레벨에서 익스플로잇을 실시간으로 차단합니다. 랜섬웨어나 악성코드가 네트워크를 타고 들어와 시스템을 감염시키기 전에 선제적으로 방어합니다.

13개 글로벌 R&D 센터

슬로바키아 브라티슬라바 본사를 포함해 전 세계 13개 연구소에서 24시간 내내 위협을 분석합니다. 전 세계 어디서 새로운 악성코드가 발생하더라도 신속하게 대응합니다.
