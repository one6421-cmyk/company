ClouDoc (클라우독)
EDMS, DLP, DRM 통합 문서중앙화 솔루션

엠클라우독(mCloudoc)이 개발한 문서중앙화 솔루션입니다.
기업 보안의 핵심인 문서 관리, 정보 유출 방지, 파일 암호화 기능을 하나의 프로그램으로 통합했습니다. 여러 보안 프로그램을 개별 도입할 때보다 예산과 운영 부담을 낮춰주며,
평소 PC의 C드라이브를 쓰던 익숙한 방식 그대로 저장만 하면 알아서 문서를 중앙화해 줍니다.

EDMS, DLP, DRM 통합 랜섬웨어 4단계 대응 윈도우 탐색기 드라이브 방식 500개 이상 고객사

윈도우 탐색기 드라이브 방식

자체 개발 탐색기 드라이브 기술로, 사용자는 C드라이브에 저장하듯 자연스럽게 사용합니다. 별도 학습이나 교육 없이 즉시 적응할 수 있습니다.

랜섬웨어 4단계 대응

백업, 자동 버전관리, I/O 패턴차단, 화이트리스트의 4단계로 대응합니다. 자동 버전관리 기능으로 폴더 단위 일괄 복구가 가능합니다.

DRM, DLP 통합 보안

PC 저장 금지, 외부 매체 통제, 클립보드 복사 제어, 화면 캡처 금지, 인쇄 제어, 프린트 워터마크 기능을 하나의 에이전트로 제공합니다.

개인정보 검출 파일 처리

기업 특성에 맞는 검출 패턴을 설정해 문서 내 개인정보를 검출하고, 파일별로 격리, 삭제, 보유 등의 조치를 할 수 있습니다.

전체 문서함 내용 검색

윈도우 탐색기에서 문서 내용을 직접 검색할 수 있으며, 전체 문서함을 대상으로 검색이 가능합니다.

외부 DRM 반출

외부 협력사에 문서를 반출할 때 암호화하여 전달하며, 인증된 사용자만 제한적으로 열람할 수 있습니다. 반출 시 협력사 편집을 허용하면 편집 후 회송도 가능합니다.

네트워크락(망 분리 대응)

물리적 변화 없이 논리적으로 내부망과 외부망을 분리하여 악성코드 감염과 정보 유출을 방지합니다.

프로젝트 버전 관리

부서 문서함의 프로젝트 폴더를 주기적으로 스냅샷 백업하여 버전별로 관리하고, 필요 시 이전 버전으로 복원할 수 있습니다.
